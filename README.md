# geter_id

Dashboard analisis saham Indonesia (IDX).

## Tujuan

Dashboard ini dibuat untuk membantu monitoring dan analisis saham Indonesia melalui satu tampilan website.

## Rencana Fitur

- Market Overview IHSG
- Harga dan historical candle saham
- Candlestick chart
- Stock Screener
- Technical Analysis
- Foreign Flow
- Broker Summary
- Bandarmology
- Fundamental Analysis
- Ownership
- Corporate Action
- Watchlist
- Smart Scanner

## Data Engine

Dashboard akan menggunakan fzn0x/idx sebagai salah satu engine utama untuk mengambil dan mengolah data pasar saham Indonesia.

Repository engine:
https://github.com/fzn0x/idx
